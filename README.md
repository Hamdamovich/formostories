# Formo Mobile - story va yangiliklar

Ilova shu fayllarni o'qiydi:
- `story.json` - story'lar (rasm yoki video)
- `news.json`  - yangiliklar
- `media/`     - rasm va videolar

Yangi story qo'shish:
1. Rasmni (JPG, 1080x1920) yoki videoni (MP4 H.264, 30 MB dan kichik) `media/` ga yuklang.
2. `story.json` ga yangi yozuv qo'shing. Manzil:
   `https://hamdamovich.github.io/formostories/media/<fayl-nomi>`
3. Commit qiling - 1-2 daqiqada ilovada ko'rinadi.

Diqqat: bu papka OCHIQ. Faqat reklama/yangilik materiallari qo'yiladi.
